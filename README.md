# _**Tasker**_

The task manager built with Laravel, featuring guest user support, real-time updates, and a clean, intuitive interface.


## Features

- ✅ Create, edit, delete tasks
- ✅ Mark tasks as completed
- ✅ Guest session (without registration)
- ✅ User registration and authentication
- ✅ Each user sees only their own tasks
- ✅ Automatic task migration upon registration/login
- ✅ Task list pagination
- ✅ Filter by status (all/active/completed)

## Installation

- Clone the repository:
```
git clone https://github.com/KirylESCAPE/Tasker.git
cd Tasker
```
- Copy environment file

```
cp .env.example .env
```
- Install Docker Engine

```
https://docs.docker.com/engine/install/ubuntu/
https://docs.docker.com/engine/install/linux-postinstall
```
- Start the Docker containers
```
docker compose up -d
```
- Access the application
```
http://localhost
```
